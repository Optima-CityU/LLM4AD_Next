# 长期记忆

长期记忆不是任务的必选项。创建任务时，你可以选择不启用记忆、使用临时记忆，或在服务就绪后使用长期记忆。

## 开始前：绑定记忆模型

进入「全局记忆」，在「默认策略」中绑定：

1. Chat 模型：用于从内容和任务过程提取结构化记忆。
2. Embedding 模型：用于将记忆转换为可检索的向量。

首次绑定 Embedding 后，其模型和维度会锁定。若 MindMemOS 服务未就绪，请先检查部署环境；此时绑定模型不会生效。

## 三种记忆范围

### 全局记忆

全局记忆属于当前用户，可在不同项目中复用。适合保存稳定的偏好、通用算法经验和长期约束。

### 项目记忆

项目记忆只属于当前项目，可由该项目内的任务复用。适合保存项目背景、领域知识、评估偏好和已经验证的结论。

### 任务记忆

任务记忆服务于当前任务的过程与结果。临时记忆仅在本次运行中保存；启用长期记忆时，任务级记忆可按任务配置参与后续注入。

任务中的高价值结论不会自动成为项目记忆。你可以在任务卡片中选择多条记忆，生成总结预览后确认保存，将其提升到项目记忆。

## 在任务中选择模式

- 不启用记忆：不向任务注入任何记忆。
- 临时记忆：默认模式，仅保留本次运行需要的任务记忆，不长期沉淀。
- 长期记忆：可使用全局、项目和任务范围的记忆。服务与模型绑定完成后才可选择。

长期记忆支持两种共享记忆获取方式：

- 自动检索：按任务配置从全局与项目范围召回相关记忆。
- 手动固定：只注入你在全局/项目选择器中勾选的记忆卡片，不自动检索共享记忆。

固定记忆只控制全局和项目范围；任务记忆仍按任务注入策略处理。已禁用的记忆卡片不会参与注入或固定选择。
