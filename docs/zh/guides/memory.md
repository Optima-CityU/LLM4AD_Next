# 长期记忆

LLM4AD 通过 MindMemOS 提供可检索的长期记忆。它的目标不是简单地保存对话，而是在每次启动算法设计任务时，把已经验证过的经验、领域知识和约束带回提示词，减少重复试错，并让同一项目中的任务逐步积累成果。

长期记忆是可选能力。创建任务时可以不使用记忆、使用仅限当前运行的临时记忆，或在服务和模型准备好后使用长期记忆。

## 先完成模型绑定

在 Web UI 中进入「全局记忆」→「默认策略」，选择并绑定：

1. **Chat 模型**：把手动输入和任务过程整理为结构化记忆卡片，例如优秀算法经验、领域知识或错误反思。
2. **Embedding 模型**：把记忆转换为向量，以便在新任务中按相关性检索。

绑定按用户生效。部署已启用 MindMemOS 且当前用户完成 Chat 与 Embedding 绑定后，任务创建页才可选择长期记忆。首次绑定 Embedding 模型后，其模型和维度会锁定；需要更换时请联系部署管理员处理对应记忆空间。

## 三层记忆如何协同

长期记忆按「全局 → 项目 → 任务」分层。越靠前的内容复用范围越广，越靠后的内容越贴近当前问题。

### 全局记忆：为新任务预设可复用经验

全局记忆属于当前用户，可跨项目复用。它适合在启动任务前主动录入或整理：

- 已验证有效的算法设计经验、启发式策略和实现模式；
- 特定问题领域的术语、约束、目标与评价原则；
- 过去失败得到的错误反思、常见陷阱和规避方式；
- 对代码风格、资源预算或结果解释的长期偏好。

把稳定、通用且值得反复使用的内容放在全局记忆中。新项目创建的任务可以自动召回这些内容，也可以由你手动指定某几张卡片固定注入。

### 项目记忆：沉淀当前项目的共同上下文

项目记忆只属于当前项目，不会进入其他项目。它建立在全局经验之上，用来保存该项目特有的背景、数据特征、评测口径、已验证结论和局部约束。

项目记忆由用户控制：你可以直接新增、编辑、禁用卡片，也可以从任务记忆中挑选有价值的经验生成项目记忆预览，确认后再保存。这样既能把一次任务的收获沉淀给后续任务，又不会把未经确认的中间过程自动扩散到整个项目。

### 任务记忆：服务当前运行并产生可筛选的候选经验

任务记忆记录当前任务运行过程中的相关经验和结果。它最贴近当前问题，适合保存本轮探索的有效思路、失败原因和待验证线索。

任务运行时会优先检索任务范围的记忆，再按任务配置决定如何注入。任务结束后，查看任务记忆卡片，选择真正有复用价值的内容，生成项目记忆摘要预览并确认保存。原始任务卡片不会因提升操作而被修改。

## 推荐使用流程

1. **准备全局经验**：先在「全局记忆」添加可跨项目使用的优秀算法经验、领域知识和错误反思。
2. **设置项目上下文**：进入项目记忆，补充仅适用于该项目的目标、约束与已验证结论。
3. **创建长期记忆任务**：在任务配置中选择「长期记忆」。
4. **选择共享记忆获取方式**：根据任务是否需要稳定、可控的上下文，选择自动检索或手动固定。
5. **配置任务记忆注入**：决定当前任务产生的记忆如何参与后续提示词。
6. **运行后复盘与提升**：从任务记忆中筛选高价值卡片，确认后沉淀为项目记忆；过时或不再适用的全局/项目卡片可编辑或禁用。

## 在任务中使用记忆

### 三种任务模式

- **不启用记忆**：不向任务注入任何记忆，适合需要完全独立对照的实验。
- **临时记忆**：默认模式，只在本次运行中使用，不沉淀为长期记忆。
- **长期记忆**：同时使用全局、项目和任务三个范围；需要服务可用且模型已绑定。

### 共享记忆：自动检索或手动固定

全局记忆和项目记忆属于共享范围，有两种使用方式：

- **自动检索**：系统从已启用的全局和项目记忆中按当前任务的相关性召回内容。可以分别控制是否包含这两个范围，以及每个范围每次提示词最多注入多少条。适合大多数探索型任务。
- **手动固定**：从全局和项目记忆中挑选指定卡片，只注入这些卡片，运行时不再自动检索共享记忆。适合复现实验、需要严格控制上下文，或只想验证某条经验的场景。

手动固定仅控制全局和项目范围；任务记忆仍会按下面的任务记忆策略参与检索和注入。

### 任务记忆：注入策略

任务记忆在运行期间产生，并始终先检索候选卡片。你可以选择：

- **TopK**：按检索相关性注入最相关的前 N 条，适合大多数任务。
- **权重模式**：按记忆管理中设置的卡片权重排序。可调节相似度与新鲜度的权衡：更高的相似度权重偏向当前问题相关的经验，更低则更重视最近产生的经验。
- **随机模式**：从候选中随机注入，增加探索多样性，适合希望避免过早固化思路的任务。

任务记忆注入数量控制每次提示词最多使用多少条任务经验；数量越大，参考信息越丰富，但会占用更多提示词空间。

## 高级检索与可靠性设置

通常保持默认即可。需要针对质量、成本或稳定性调优时，可在任务配置的高级设置中调整：

- **搜索策略**：`fast` 延迟低，适合常规检索；`agentic` 会做更深入的检索规划，可能更准确，但更慢且成本更高。
- **重排与分数阈值（暂不支持）**：界面保留了相关配置入口，但当前部署暂不提供重排能力，相关设置不会生效。
- **请求/写入超时与提取语言**：适合网络较慢、记忆提取量较大或需要固定中英文提取结果的场景。
- **失败放行**：开启后，MindMemOS 暂时不可用时任务仍会继续，但本轮会跳过远程记忆；关闭后，记忆服务失败会使任务失败，适合严格验证记忆效果的实验。

## 注意事项

- 记忆卡片是否启用会直接影响检索：被禁用的卡片不会被自动检索、手动固定或注入任务。
- 全局记忆适合稳定、通用的知识；项目记忆适合项目专属结论；不要把短期试验噪声直接写入全局范围。
- 从任务提升到项目记忆需要用户确认，避免把一次偶然结果变成后续任务的默认前提。
- MindMemOS 服务不可用或模型未绑定时，长期记忆不可选；可继续使用临时记忆或不启用记忆。
