# 长期记忆

LLM4AD 通过 MindMemOS 提供可检索的长期记忆。它不是任务的必选项：创建任务时可以不启用记忆、使用临时记忆，或在服务与模型就绪后使用长期记忆。

## 配置并绑定记忆模型

在 Web UI 中进入「全局记忆」→「默认策略」，依次选择并绑定：

1. **Chat 模型**：从任务过程、手动输入等内容中提取结构化记忆。
2. **Embedding 模型**：将记忆转换为向量，供后续检索使用。

绑定前请确认部署已启用 MindMemOS 服务。首次绑定 Embedding 模型后，其模型与维度会锁定；如需更换，请联系部署管理员处理对应记忆空间。

## 三类记忆

### 全局记忆

全局记忆属于当前用户，可在不同项目间复用。适合保存稳定的偏好、通用算法经验和长期约束。

### 项目记忆

项目记忆只在当前项目中可用，供该项目下的任务复用。适合保存项目背景、领域知识、评估偏好和已验证结论。

### 任务记忆

任务记忆记录当前任务的过程与结果。你可以从任务卡片中选择高价值内容，生成总结预览并确认后提升为项目记忆；不会自动提升。

## 在任务中使用

- **不启用记忆**：不向任务注入记忆。
- **临时记忆**：默认模式，只服务于本次运行，不会沉淀为长期记忆。
- **长期记忆**：可使用全局、项目和任务三个范围的记忆；需先完成服务与模型绑定。

长期记忆支持两种共享记忆获取方式：

- **自动检索**：从全局和项目记忆中召回与当前任务相关的内容。
- **手动固定**：仅注入你选中的全局或项目记忆卡片，不进行自动检索。

## 注意事项

- 模型绑定按用户生效；每位使用者首次使用前都需要完成绑定。
- 手动固定只控制全局和项目记忆，任务记忆仍按任务配置处理。
- 被禁用的记忆卡片不会参与自动检索、手动固定或任务注入。
- MindMemOS 服务不可用或模型未绑定时，无法正常使用长期记忆；请先检查服务状态和绑定配置。
