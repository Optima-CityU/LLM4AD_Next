# 隐私协议 draft

适用于 LLM4AD 公开展示网站与文档站。若您自行部署 LLM4AD 后端、启用账号系统、任务管理、文件上传或其他服务端能力，应根据实际部署方式另行制定隐私政策。

更新日期：2026 年 6 月 18 日。

LLM4AD（以下简称“我们”）尊重并保护用户隐私。我们遵循合法、正当、必要和最小化原则处理与网站访问、文档浏览和本地 CLI 使用相关的信息。本协议用于说明我们不会做什么、会收集什么、Cookie 如何使用、CLI 本地数据如何保存，以及您如何联系我们。

## 一、适用范围

本协议适用于：

- 访问 LLM4AD 公开展示网站、文档站、示例页面和相关静态资源的行为。
- 通过网站链接下载、阅读或使用 LLM4AD 开源代码与文档的行为。
- 运行 `llm4ad` CLI 时与本地配置、第三方 LLM Provider 调用相关的隐私说明。

本协议不适用于：

- 您访问 GitHub、LLM Provider、包管理平台或其他第三方网站、API、模型服务时产生的数据处理活动。
- 您或第三方自行部署的 LLM4AD 服务端、数据库、管理后台、账号系统或日志系统。
- 您在本地机器、私有服务器、企业内网或云资源中保存和处理的任务数据、代码、配置、评估结果与运行日志。

## 二、我们不做什么

- 网站不做跨站追踪，不建立用户画像，不基于访问行为进行个性化广告投放。
- 我们不会向第三方出售、出租或以交易方式提供任何可识别个人身份的数据。
- 网站使用我们自行部署的 Plausible Community Edition 进行访客统计，仅用于了解站点访问情况并改进用户体验；统计结果不用于商业用途，不与账号身份关联，也不用于识别特定个人。
- 仓库默认前端不内置 Google Analytics、Sentry、百度统计等第三方广告、跨站追踪或错误追踪脚本。

## 三、我们会收集什么

为保障网站可用性、安全性和基础错误诊断，网站服务器可能自动记录以下匿名或低识别度访问日志：

- 网络请求信息：IP 地址、访问时间、访问路径、HTTP 状态码、来源页面（`Referer`，如浏览器提供）。
- 客户端信息：`User-Agent`、浏览器类型、操作系统类型、语言设置。
- 运行诊断信息：静态资源加载失败、服务不可用、异常状态码等与站点维护相关的信息。
- 访客统计信息：通过自部署 Plausible Community Edition 生成的页面访问量、访问来源、设备类型、浏览器类型、操作系统类型、国家或地区等聚合统计数据。

上述日志仅用于：

- 保障网站稳定运行、排查访问错误和安全异常。
- 统计站点整体可用性与资源访问情况。
- 了解公开网站与文档页面的使用情况，帮助改进内容组织和用户体验。
- 防范恶意请求、爬虫滥用、攻击或其他影响服务可用性的行为。

Plausible 统计数据仅在我们自行部署的社区版服务中处理和展示，不与用户账号、任务数据、API Key、上传文件或其他身份信息关联，不用于广告投放、用户画像或商业变现。

## 四、Cookie 和本地存储

网站仅使用必要的 Cookie 或浏览器本地存储，用于保存不涉及身份识别的偏好设置，例如：

- 主题色、明暗模式。
- 语言切换。
- 文档 UI 展开状态或类似展示偏好。

我们不使用任何第三方广告 Cookie、跨站追踪 Cookie 或营销追踪像素。自部署 Plausible Community Edition 的访客统计不依赖用于识别个人身份的 Cookie，也不与登录身份绑定。您可以通过浏览器设置清除或禁用 Cookie；禁用后，部分偏好设置可能无法保留，但不影响文档浏览和代码下载。

## 五、CLI 本地数据说明

`llm4ad` CLI 在用户本机运行。除非您自行配置远程服务或第三方 Provider，LLM4AD 不会接收您的本地任务数据。

- API Key 可能以明文形式存放在本地文件 `~/.llm4ad/settings.yaml`，由用户自行保管。
- 推荐写成 `api_key: ${OPENAI_API_KEY}` 或 `auth_token: ${ANTHROPIC_API_KEY}` 形式，从环境变量读取，避免明文密钥落盘。
- 本地运行产生的任务描述、配置文件、生成代码、评估结果、日志、`checkpoint` 和 `best` 目录默认保存在用户指定的本地工作区。
- LLM4AD 不会将 API Key、任务描述、业务数据、生成代码或评估结果回传到任何远程服务器。
- 调用 OpenAI、Anthropic、DeepSeek、Azure OpenAI 或其他 OpenAI-compatible Provider 时，相关请求会发送至用户配置的 Provider 端点，并受该 Provider 的服务条款、隐私政策、数据保留政策和费用规则约束。
- 因调用第三方 LLM Provider 产生的费用、配额消耗、数据处理和合规责任由用户自行承担。

如您在任务描述、数据文件、代码仓库或评估输入中包含个人信息、商业秘密、受监管数据或第三方数据，请在运行前确认您具有合法处理依据，并根据需要采取脱敏、匿名化、访问控制或私有化部署措施。

## 六、数据共享、转让与公开披露

除以下情形外，我们不会共享、转让或公开披露通过网站访问日志获得的信息：

- 根据法律法规、司法机关、行政机关或监管机构的合法要求必须提供。
- 为处理安全事件、攻击行为、服务滥用、违法违规行为或权利争议所必需。
- 在不识别特定个人的前提下，对访问量、错误率、可用性等进行汇总统计。
- 获得您的明确授权或由您主动公开提供。

若未来发生组织合并、项目转移、运营主体变更或服务迁移，并涉及本协议项下数据处理方式的实质变化，我们将在合理范围内通过网站公告、仓库说明或其他可触达方式更新说明。

## 七、数据保存与安全

我们采取与静态网站和开源项目维护相匹配的合理安全措施，降低访问日志被未经授权访问、泄露、篡改或丢失的风险，包括但不限于访问权限控制、最小化留存、日志保留期限限制和基础安全监测。

请您理解，互联网传输和开源软件使用环境无法保证绝对安全。您应妥善保管自己的 API Key、本地配置文件、运行目录、代码仓库权限和第三方 Provider 账号，避免将密钥提交到公开仓库、截图、日志或 issue 中。

## 八、您的权利

在适用法律允许的范围内，您可以通过本协议“联系方式”所列渠道向我们提出与个人信息相关的请求，包括：

- 查询我们是否保存了与您相关的访问日志。
- 请求更正、删除或匿名化与您相关的可识别信息。
- 请求说明数据处理目的、范围、保存期限或安全措施。
- 撤回您此前主动提供的信息或授权。

为保障安全，我们可能需要您提供必要信息以验证请求与相关数据之间的关联。对于无法验证身份、无法定位数据、请求明显重复或超出合理范围的情况，我们可能无法响应或仅在合理范围内响应。

## 九、跨境传输

公开网站和文档站本身不主动向境外第三方传输用户提交的个人信息。由于网站托管、CDN、GitHub、包管理平台或第三方 Provider 的基础设施可能位于不同国家或地区，您访问这些第三方服务时产生的数据传输将受相应第三方条款约束。

当您使用本地 CLI 调用境外 LLM Provider 或云服务时，相关请求、输入内容和响应内容可能发生跨境传输。请您根据自身所在地法律法规、所在机构制度和数据敏感程度自行判断是否适合使用相应 Provider。

## 十一、协议更新

我们可能根据项目功能、网站部署方式、法律法规或社区维护需要更新本协议。更新后的协议将在本页面发布，并以页面标注的更新日期为准。

如更新涉及数据收集范围、使用目的、共享方式、保存期限或用户权利的实质变化，我们会尽量通过网站公告、仓库说明或 release note 提示。若您不同意更新后的协议，可以停止访问网站或使用相关在线页面；这不影响您在开源许可证范围内继续使用已获取的代码和文档。

## 十二、联系方式

- Bug 报告、功能建议、隐私问题或数据删除请求：通过 GitHub Issues 发起。
- 其他问题：通过 GitHub Issues 发起讨论，并在标题中标明 `privacy` 或 隐私。

请不要在公开 issue 中粘贴 API Key、访问令牌、个人身份信息、商业秘密、未脱敏日志或受监管数据。如确需提供敏感材料，请先在 issue 中说明情况，等待维护者确认安全的沟通方式。
