# Proposal research foundation and feasibility

Read [the foundation and feasibility guide](../proposal-foundation-feasibility/references/foundation-and-feasibility.md)
when checking capabilities, resources or project risks.

Use only real preliminary work, team capabilities, facilities, data access,
collaborations and institutional support from author facts or trusted sources.
Explain what project task each item enables and which risk it reduces; a
biography or equipment list is not sufficient evidence of feasibility.

Assess goal, technical, resource, schedule and risk feasibility against the
actual objectives and methods. Keep achieved results separate from proposed
work and conditional controls. Ask for consequential missing facts rather than
inventing publications, people, facilities, access or resources.

The main agent revises the relevant Markdown foundation/feasibility argument
within the author's scope. Preserve uncertainties and report actionable gaps;
these judgments are not scientific validation gates in the backend.
