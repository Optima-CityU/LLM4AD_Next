# Proposal research methods

Read [the methods and technical-route guide](../proposal-methods/references/research-methods.md)
for method design, formalization or evaluation questions.

Connect the research problems to a coherent technical route. Specify
assumptions, inputs, procedure, comparison boundary, evaluation evidence,
failure conditions and realistic fallbacks at an appropriate technical depth.
Use meaningful equations where useful and define notation consistently in
Markdown mathematics; equations are not decoration.

For each hypothesis, distinguish observations that would support it from those
that would falsify it. Include relevant baselines, metrics, ablations,
uncertainty and reproducibility conditions without claiming unavailable data,
equipment, measurements or implementation maturity.

Ask about a consequential method, access or evaluation choice when the author
must decide it. The main agent integrates the requested method/design changes
into canonical Markdown and preserves related citations and author edits.
Scientific quality checks are guidance, not backend publication requirements.
