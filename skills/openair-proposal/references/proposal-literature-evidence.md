# Proposal literature and evidence

Use this method for a focused evidence gap, literature synthesis or citation
correction. Read [the evidence and references guide](../proposal-literature-evidence/references/literature-and-references.md).

Select relevant foundation, author sources and existing proposal text. Build
an evidence map around named research questions, then investigate only the gaps
needed for the request. Use available approved research tools for discovery,
source inspection and verified metadata; a tool count or particular provider
is not a completion gate. Existing reliable author sources may already answer
the question. Search snippets and model memory alone do not establish a claim.

Read bounded relevant passages of promising primary sources. Distinguish
established findings, limitations, contrary evidence and the proposed gap.
Organize the literature by research thread, mechanism or comparison boundary,
not a list of papers. Report search scope and coverage limits.

Write the synthesis in S2 and the relevant canonical passages. New proposals use
numbered in-text references matched to S4, `4-参考文献.md`, following first
occurrence across chapter order. Reconcile affected markers and entries together
while preserving source identities. Preserve existing citation styles and
legacy BibTeX keys; merge verified additions into `references.bib` only when it
is already the chosen source. Do not require a new `.bib` file or numeric
literature, venue, date-window or percentage quotas. Do not invent authors,
titles, identifiers, venues, years, DOI values or results, and do not overwrite
author annotations.

arXiv is a discovery source, not evidence of peer review. If evidence access or
metadata verification fails, keep the gap visible and continue independent work
without fabricating support or declaring an absent literature consensus.
