# Proposal innovation and work plan

Read [the innovation and planning guide](../proposal-innovation-plan/references/innovation-and-plan.md)
when assessing differences, milestones or expected outcomes.

State innovations as specific differences in question, mechanism, method,
integration or validation. Tie each to a documented limitation, work package
and evidence path. Compare with the nearest relevant work and avoid unsupported
priority or performance claims.

Build a plan around technical dependencies, observable milestones, decision
points and fallbacks rather than equal calendar slices. Distinguish expected
outcomes from achieved facts. Do not infer fixed publication counts, patents,
venues, performance values or delivery targets without author support.

Keep innovation/planning conceptually distinct from achieved foundation and
feasibility, while allowing the main agent to integrate consistent revisions
across the requested canonical Markdown passages.
