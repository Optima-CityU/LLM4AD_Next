# Proposal rationale and value

Read [the purpose and value guide](../proposal-rationale/references/purpose-and-value.md)
when developing the necessity, significance or application value of the work.

Connect the project foundation and verified evidence to a precise research
limitation and a coherent reason to investigate it. Separate research purpose
from academic, practical and potential application value. Ground factual
claims in inspected sources and preserve reference identities and any legacy
bibliography keys.

Link each value claim to the proposed capability, beneficiary or research
consequence and the conditions under which it would matter. Do not present an
expected result as achieved or enlarge scope to sound more ambitious. Ask about
consequential impact or audience choices only when current author materials do
not settle them.

The main agent integrates the requested rationale/value revision into canonical
Markdown while preserving author decisions and related argument links. A method
boundary is a conceptual distinction, not ownership of a separate stage file.
