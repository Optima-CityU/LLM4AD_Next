# Plan mode

Generate compact alternative organization strategies without generating final knowledge documents.

1. Read every source in the host inventory. Read several sources in parallel when the available tools support it.
2. Use the original display filenames from the inventory in source analysis, not host-added ordering prefixes.
3. Identify real organization choices. Normally produce 2–4 candidates; use one when no meaningful alternative exists and at most 8 for complex material. Never manufacture duplicate candidates.
4. Describe document boundaries and easily lost exceptions rather than copying source content into the plan.
5. Map every important source section to at least one planned document. State why any material is intentionally excluded.
6. Prefer additional parallel documents over compressing unrelated material into a broad summary.
7. If clarification tools are available, ask only about ambiguity that materially changes boundaries or fidelity. Follow the host's question and interaction limits.
8. If the host exposes `save_source_analysis`, `upsert_plan_candidate`, and `finalize_plan_set`, save the analysis first, upsert each candidate, then finalize the recommended candidate. If those tools are unavailable, write the planning contract from `contracts.md` to the host-designated plan path.
9. Do not create or edit source documents or final organized documents in this mode.
