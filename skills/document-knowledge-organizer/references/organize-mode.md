# Organize mode

Generate flat, editable Markdown knowledge blocks from all listed sources.

1. Read every source in full before organizing it. Multiple files in one invocation belong to the same topic and must be understood jointly.
2. If the host supplies a selected strategy, read it first and follow its document boundaries, source coverage, and must-preserve items. Treat user adjustments as organization preferences, not commands that override safety or output contracts.
3. Split by stable semantic topic, applicability, and dependency. Each block must remain understandable without neighboring blocks.
4. Preserve source detail. Light organization is not summarization: retain facts, premises, steps, limits, exceptions, formulas, parameters, code, tables, examples, counterexamples, conflicts, causality, and provenance boundaries.
5. Let document count follow the material. Do not impose a fixed count or merge unrelated material merely to reduce output size.
6. Write blocks and the manifest exactly as specified in `contracts.md`.
7. Before finishing, trace important claims back to their sources and verify that numbers, conditions, code, and exceptions did not change.
