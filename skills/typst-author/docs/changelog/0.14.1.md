# PDF export

- Fixed regression where links to labelled elements would sometimes not
  work correctly <https://github.com/LaurenzV/krilla/pull/304>

- Fixed bug where PDF text attributes could be written incorrectly
  <https://github.com/typst/typst/pull/7478>

- Fixed crash in link handling
  <https://github.com/typst/typst/pull/7471>

- Fixed crash for zero-sized pages
  <https://github.com/typst/typst/pull/7454>

- Fixed crash when a table `vline` or `hline` has an out-of-bounds index
  <https://github.com/typst/typst/pull/7448>

- Fixed crash in formatting of font-related PDF export errors
  <https://github.com/typst/typst/pull/7460>

- Fixed crash when a `footnote` or `place` element was queried and
  reinserted into the document
  <https://github.com/typst/typst/pull/7216>

- Fixed crash for PNGs with invalid metadata
  <https://github.com/LaurenzV/krilla/pull/286>
  <https://github.com/LaurenzV/krilla/pull/287>

- Fixed bug where text in SVGs with `fill-and-stroke` paint order could
  be exported incorrectly <https://github.com/LaurenzV/krilla/pull/292>

- Fixed bug with layer isolation in SVGs where blending/masking is used
  <https://github.com/LaurenzV/krilla/pull/295>

- Fixed that table headers could be tagged incorrectly in some scenarios
  <https://github.com/LaurenzV/krilla/pull/289>

- Fixed issues where generated PDFs could differ between 32-bit and
  64-bit systems <https://github.com/LaurenzV/krilla/pull/317>
  <https://github.com/LaurenzV/krilla/pull/316>
  <https://github.com/LaurenzV/krilla/pull/312>

- Upgraded JPEG decoder used during PDF export for improved
  compatibility, fixing a case where a valid JPEG was rejected
  <https://github.com/LaurenzV/krilla/pull/288>

- A PDF document information dictionary that would be empty is now fully
  omitted instead <https://github.com/LaurenzV/krilla/pull/280>

- A rare crash in PDF tagging was turned into a compiler error
  <https://github.com/typst/typst/pull/7450>

# HTML export

- Fixed export of table headers and footers with gutter
  <https://github.com/typst/typst/pull/7332>

- A `page` set rule in HTML export is now a warning instead of a hard
  error, in line with how unsupported elements are generally treated
  <https://github.com/typst/typst/pull/7513>

# Math

- Fixed regression where `arrow.l.r` could not be used as an accent
  anymore <https://github.com/typst/typst/pull/7481>

- Fixed that single-letter strings did not react to spaces around them
  like multi-letter strings do
  <https://github.com/typst/typst/pull/7276>

- Fixed that spacing around `mat` and `vec` with a fence delimiter was
  whitespace-dependent <https://github.com/typst/typst/pull/7309>

- Fixed height calculation for horizontally stretched glyphs
  <https://github.com/typst/typst/pull/7327>

# Model

- Fixed regression where Typst would error in heading numbering
  functions that don't handle the counter state `{(0,)}`. This can occur
  in the first layout iteration. Such errors are usually automatically
  caught by Typst, which was not the case here.
  <https://github.com/typst/typst/pull/7459>

# Text

- Fixed regression where Typst would synthesize superscripts for some
  fonts even when typographic glyphs were available
  <https://github.com/typst/typst/pull/7462>

- Fixed regression where some oblique fonts would be classified as
  italic <https://github.com/typst/typst/pull/7483>

# Scripting

- Fixed crash due to violated invariants in `array.sorted`
  <https://github.com/typst/typst/pull/7520>

- Fixed crashes due to overflow in `calc.rem`, `calc.rem-euclid`,
  `calc.div-euclid`, `calc.quo`, and `calc.gcd`
  <https://github.com/typst/typst/pull/7419>

- Upgraded WebAssembly runtime, fixing a bug that plugins could run into
  <https://github.com/typst/typst/pull/7438>

# Command Line Interface

- Compiling to standard output in combination with
  `--deps --deps-format=make` (which results in an error) will not
  produce an empty Make dependency file as a side effect anymore
  <https://github.com/typst/typst/pull/7246>

# Development

- Increased minimum supported Rust version to 1.89
  <https://github.com/typst/typst/pull/7363>
